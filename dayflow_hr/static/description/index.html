Dayflow HRMS

"Every workday, perfectly aligned."

A modern Human Resource Management System extending Odoo 17 core modules (hr, hr_attendance, hr_holidays).

  • Role-Based Access: Tailored views and record-level rules for Employees vs HR Officers / Admins.
  • Attendance: Real-time clock in/out with status calculation (Present, Half-day, Absent, On Leave).
  • Time Off: Support for Paid, Sick, and Unpaid leave workflows with approval notes.
  • Profiles & Salary: Granular field security ensuring employees can only edit contact details while admins manage full records and salaries.
